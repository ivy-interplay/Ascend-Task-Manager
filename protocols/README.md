# Protocols

This directory contains protocol definitions for the Task Manager V02.
Each protocol describes a specific behavior or workflow the task manager supports.

## Protocol Index

| Protocol | File | Description |
|----------|------|-------------|
| New Task Manager Transcript Protocol | [new-task-manager-transcript-protocol.md](new-task-manager-transcript-protocol.md) | Reads an uploaded transcript and maps its content to existing cards, updating only those cards with the extracted task data. Never creates new cards without explicit user instruction. |
